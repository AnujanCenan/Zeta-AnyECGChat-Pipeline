# =============================================================================
# REQUIRED SOURCE PATCHES (not pip-installable -- these are edits to the
# vendored repo code itself, needed regardless of which package versions
# above you use, since the root cause is an internal transformers API that
# moved, not a missing package)
# =============================================================================
# 1. anyecg/ecg_language_modeling.py: ECG_Language_Model.__init__ hardcodes
#    two absolute paths specific to the original authors' machine
#    (/mnt/sda1/xxxx/... and /home/xxxx/...). Patch it to accept
#    `ecg_encoder_ckpt_path` and `llm_model_id` as constructor parameters
#    (with those same strings kept as defaults, for backward compatibility
#    with anyECG-chat's own train.py/inference.py call sites).
#
# 2. models/cross_layer.py (ZETA): change
#        from transformers.modeling_utils import (
#            apply_chunking_to_forward, find_pruneable_heads_and_indices, prune_linear_layer)
#    to
#        from transformers.pytorch_utils import (
#            apply_chunking_to_forward, find_pruneable_heads_and_indices, prune_linear_layer)
#    Root cause: these three functions stopped being re-exported from
#    transformers.modeling_utils starting at transformers>=4.47 -- confirmed
#    via a public transformers-ecosystem GitHub PR fixing the identical
#    ImportError in a different project. This affects every transformers
#    version pinned above (4.48+), not just newer ones.
#
# If you hit a similar ImportError elsewhere in ZETA's models/cmelt.py
# (which imports T5EncoderModel, BertConfig, BertPredictionHeadTransform
# directly from transformers' internal model files) -- these are more
# stable, commonly-copied public classes and I have no evidence they've
# moved, but this has NOT been independently confirmed against transformers
# 4.50.0 specifically. If one of these does fail to import, it's the same
# category of fix: check the error for where the symbol now lives.
# =============================================================================
